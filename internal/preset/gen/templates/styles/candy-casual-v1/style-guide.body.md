

# “糖果休闲”视频风格说明书

- 版本：1.0
- 适用：轻松科普、生活技巧、习惯养成、成长激励、面向新手的产品介绍
- 基准画幅：{{CANVAS}}，30fps

## 1. 风格定位

“糖果休闲”借用休闲手游的界面语言讲道理：一个观点是一次奖励弹窗，一次对比是一关的评星结算，一套步骤是一张签到日历，一份清单是一排商店货架。观众不需要玩过任何游戏，也能从“点亮、领取、解锁”这些动作里读懂进度和收获。

五个关键词：

- **轻松**：颜色明快、形状圆胖，降低知识的门槛。
- **友好**：粗描边与实底让每个元素都清清楚楚，不靠细线和微妙灰阶。
- **有成就感**：进度被点亮、星星被集齐、奖励被收下，每段信息都有“完成”的落点。
- **明快**：图形可以弹，文字很快落定；节奏轻快但不吵。
- **不幼稚**：文案仍是成年人能信的解释，游戏元素只做隐喻，不做卖萌。

## 2. 适用与不适用

适合：

- 生活技巧、健康习惯、学习方法、理财入门等“做到就有收获”的内容。
- 需要降低门槛的轻科普和新手教程。
- 成长激励、打卡挑战、清单盘点类视频。

不适合直接套用：

- 严肃新闻、灾难、医疗风险、法律纠纷等需要克制与庄重的题材。
- 需要大量精密数据、代码或复杂系统图的深度技术讲解（更适合“清晰系统蓝图”）。
- 涉及真实金钱抽奖、博彩或诱导消费的内容——本风格的“奖励”只能是隐喻。

## 3. 品牌叙事原则

每个镜头先写一句体验描述，再写布局：

> 观众此刻完成了哪一步？得到了什么？哪一个奖励或状态被点亮并留在画面上？

优先使用以下叙事动作：

1. **领任务**：抛出问题、目标或挑战。
2. **闯关**：给出方法、对比或步骤。
3. **结算**：用星级、分数或进度说明效果。
4. **领奖**：把结论变成一个被收下的奖励。
5. **解锁**：引出下一章或下一个技巧。

## 4. 画布、安全区与网格

### 4.1 五层安全区

安全区以根目录 `frame.md` 的 `safe_area` 为准，以下为语义说明：

| 区域 | 用途 |
|---|---|
| 结构装饰区 `structural` | 糖果条纹、圆点、散落的小星星等弱装饰 |
| 主内容区 `main_content` | 面板、货架、日历等主体图形 |
| 关键文字区 `critical_text` | 标题、数字、按钮字、结论 |
| 封面标题区 `cover_title` | 第 0 帧封面标题与主面板 |
| 字幕区 `subtitles` | 可选内嵌字幕 |

{{AVOIDANCE_ZONES}}，属于关键避让区。装饰可以进入，但标题、数字、结论、按钮字和字幕不得进入。

### 4.2 主内容轴

- 左起 {{CONTENT_LEFT_PX}}px，标准宽度 {{CONTENT_WIDTH_PX}}px。
- 弹窗式面板可以水平居中于主内容区，但面板内的标题与按钮字仍要落在关键文字区内。
- 面板上方的“缎带标题”允许略宽于面板，但不得越出主内容区。

## 6. 字体与信息层级

### 6.1 字体角色

- 展示字 `ZCOOL KuaiLe`（仅 400）：封面、镜头标题、面板标题、按钮字。不设置加粗，避免伪粗体。
- 正文 `Noto Sans SC`：说明文字与多行段落，常用 600，强调 700。
- 数字 `Fredoka` 600/700：分数、金币数、倍率、天数、`LV`、`x3` 等拉丁短标签。
- 所有字体都随项目下发，必须写 `@font-face`，不依赖系统字体。

### 6.2 字号

| 角色 | 字号 | 字体 / 字重 |
|---|---:|---|
| 封面标题 | 84–120px | ZCOOL KuaiLe 400 |
| 镜头标题 | 50–68px | ZCOOL KuaiLe 400 |
| 正文 / 结论 | 26–36px | Noto Sans SC 600–700 |
| 标签 / 按钮小字 | 24–30px | ZCOOL KuaiLe 400 或 Noto Sans SC 700 |
| 大数字 | 56–140px | Fredoka 700 |

中文字不小于 24px。标题行距 1.02–1.12，正文行距约 1.38。

## 7. 空间、描边与圆角

### 7.1 留白节奏

- 同组元素：14–24px。
- 堆叠卡片：至少 20px（唇边高度另算）。
- 不同信息组：36–60px。
- 主面板内边距：32–44px。
- 次级格子内边距：22–30px。
- 标签、星星、金币距边缘：至少 24px。
- 列表、日历格、进度条最后一行到底边：至少 24px。

### 7.2 描边与唇边

- 主面板、按钮：6px `ink` 描边。次级格子、图标：4px。最细 3px，不使用细线。
- 3D 唇边：同形状向下偏移 8–12px，填充 `ink`，放在主体之下。
- 高光：`white` 不透明度 0.35–0.55 的圆角条，贴在形状上沿内侧。

### 7.3 圆角

- 16px：小标签、日历小格。
- 24px：按钮、字幕底、次级格子。
- 36px：常规面板。
- 48px：弹窗主面板。
- 999px：胶囊按钮、进度条、倍率标签。
- 50%：金币、圆形徽章。

不要临时发明 20、30、40px 这类相近圆角。

## 8. 组件语言

### 弹窗面板

白底、6px 描边、48px 圆角、底部唇边；顶部可挂一条 `candy_pink` 或 `grape` 缎带标题。一镜只有一个弹窗。

### 按钮

胶囊或 24px 圆角，填 `mint`（领取、完成）、`candy_pink`（主行动）或 `sky`（次级），`ink` 字，带唇边与上沿高光。按钮是结论的落点，不是装饰。

### 星星与金币

星星为圆角五角星，点亮用 `lemon`，未点亮用 `bubble_tint`，都带 `ink` 描边。金币为 `lemon` 圆形，中间可放 `Fredoka` 数字。数量要对应真实含义，不随手撒满屏。

### 进度条与格子

胶囊形进度条，底色 `bubble_tint`，已完成部分用 `mint` 或 `candy_pink`；日历格已签到打 `mint` 勾，当前格用 `lemon` 高亮。

### 缎带与标签

缎带是标题的承托，不承载长段文字；标签用 `grape` 底白字或 `lemon` 底 ink 字。

## 9. 四类镜头骨架

### 9.1 奖励弹窗（proposition）

用于封面、钩子、章节开场和强结论。一个弹窗主面板承载一句大判断，缎带标题 + 大奖励图形 + 领取按钮。第二焦点至多是面板外一枚浮动奖励。

![奖励弹窗示例](../assets/style-guide/examples/proposition.png)

### 9.2 关卡评星（comparison）

用于做法对比、前后对照、“一星与三星的差距”。两张结算卡上下或左右对照，星级和分数说明差距，结论单独放在底部按钮或横幅里，不塞进比较卡。

![关卡评星示例](../assets/style-guide/examples/comparison.png)

### 9.3 签到日历（process）

用于步骤、每日习惯、进度累积和阶段解锁。格子按顺序排列，已完成打勾、当前格高亮、未来格锁定；终点格放大奖励。不做普通项目符号列表。

![签到日历示例](../assets/style-guide/examples/process.png)

### 9.4 商店货架（capability_deck）

用于清单、工具箱、选项总览和收获盘点。每件“商品”是一个带唇边的格子：图标、名称、一句说明、价格标签（用“时间”“步骤”等非金钱单位）。推荐项用缎带标记，成为视觉锚点。

![商店货架示例](../assets/style-guide/examples/capability_deck.png)

## 10. 动画语法

### 10.1 三阶段

- **Build 30%**：主面板或主图形 POP / DROP_IN 入场，文字随后落定。
- **Breathe 45%**：信息稳定可读，至多一种环境动作（如背景小星星缓慢闪烁）；也可以完全静止。
- **Resolve 25%**：STAR_BURST、STAMP 或 UNLOCK 锁定结论，然后快速退场。

### 10.2 品牌动作词

- `POP`：从 0.6 缩放到 1，`back.out(1.6)`，0.30–0.45s。
- `DROP_IN`：从上方 60–120px 落下，`back.out(2.2)`，0.35–0.55s。
- `STAR_BURST`：星星依次点亮（缩放 + 轻微旋转），每颗间隔 0.10–0.16s；可伴随固定坐标的短促放射线。
- `COUNT_UP`：数字从 0 递增到目标值，0.5–1.2s，结尾不弹跳。
- `SQUASH`：按钮被“按下”——纵向压缩到 0.9 再回弹，唇边同步变薄。
- `UNLOCK`：锁图标晃动后打开，格子从 `bubble_tint` 变为亮色。
- `STAMP`：“完成”“已领取”章从 1.3 缩放落下，`power3.out`。

入场 0.28–0.55s，退场 0.16–0.35s，第一动作延迟 0.10–0.30s，避免第 0 帧跳变。一个镜头中相同 ease 的独立 tween 不超过两个。

### 10.3 弹性的边界

- `back.out` 和轻度 `elastic.out(1, 0.6)` 只用于面板、按钮、星星、金币等图形。
- 文字在 0.35s 内落定，落定后不再弹动、摇摆或呼吸缩放。
- 不做持续的待机弹跳和果冻晃动；环境动作每镜最多一种。
- 撒币、星爆、彩纸等粒子使用固定坐标或固定种子，且不得覆盖文字。

### 10.4 转场

- 同一关卡内：面板收起再弹出，或镜头向下“翻页”。
- 新章节：0.20–0.40s 的圆形擦除或方向性推移。
- 重要信息进入后稳定 1.0–1.8s，再允许切镜头。

## 11. 字幕、口播与声音

### 字幕

- 可选，最多两行。
- 34–40px，最大宽度 {{SUBTITLE_MAX_WIDTH_PX}}px，行距 1.30–1.40。
- 每行建议不超过 15 个全角字符。
- 专有名词、英文词组、数字与单位不可拆开。
- `rgba(59,30,84,0.88)` 葡萄紫深底、白字、14×24px 内边距、24px 圆角。
- 字幕不得遮挡面板标题、星级、数字和按钮。

### 口播

- 保持人声原速，语气可以轻快。
- 结算、领奖等节点后留真实停顿，让画面的“完成感”落下。

### BGM 与 SFX

- 48kHz 双声道。
- BGM 可以轻快（木琴、拨弦、轻打击），但有人声时下压 6–10dB。
- SFX 只标记钩子、星星点亮、领取、解锁和结论；一串星星用一个 cue，不逐颗配音。
- 单个 SFX cue 增益 -18 至 -12dB，同时最多两个。
- 成片目标 -16 LUFS ±1，真峰值不高于 -1 dBTP，LRA 2–6 LU。

## 12. 首帧封面

- 第 0 帧必须是完整完成态：弹窗、缎带、标题、星星全部就位。
- 默认两行，最多三行；单行不超过 9 个全角字符。
- 标题最大宽度 {{COVER_MAX_WIDTH_PX}}px，字号 84–120px，ZCOOL KuaiLe。
- 文本与其直接底色对比度不低于 7:1：`ink` 字放在 `white` / `lemon` / `canvas` 上，或 `white` 字放在 `ink` 实底上。
- 30fps 下至少稳定 18 帧后才允许转场。
- 不得使用黑帧、空白、从 0 缩放的中间态或必须等动画完成才看懂的封面。

## 13. 不可变项与可变项

### 不可变

- 画布、核心色、字体角色、安全区、空间比例、描边与圆角。
- 四类骨架的语义用途。
- 动作词、三阶段节奏、“文字快速落定”、人声优先的声音目标。
- 字幕、封面、禁用项和验收门槛。

### 可变

- 镜头骨架选择和组合。
- 图形隐喻、图标、格子与星星数量、局部构图。
- 内容图片、产品截图和第三方 Logo（仅作内容素材）。

### 知识产权边界

不得复制任何商业游戏的 Logo、角色、吉祥物、特定糖果造型、关卡地图或界面布局；不得模仿其字标。所有星星、金币、宝石、面板都用本规范的几何形状重新绘制。

## 14. Do / Don’t

### Do

- 用“领取、点亮、解锁”对应真实的进度和收获。
- 亮色底上用 `ink` 字，或给文字铺实底。
- 让最重要的图形先弹出，文字紧跟着落定。
- 每个主体都有粗描边和向下的唇边，保持同一光源。
- 奖励图形少而准，让一个大奖励成为视觉锚点。

### Don’t

- 不在粉、薄荷、天蓝、柠檬底上直接放细白字。
- 不用细线、玻璃拟态、霓虹发光或渐变文字。
- 不让文字持续弹跳、摇摆或呼吸。
- 不同时弹出两个面板，不让彩纸粒子盖住文字。
- 不出现真实金钱价格、抽奖、开箱等博彩暗示。
- 不复制商业游戏的 Logo、角色和界面。

## 15. 制作与验收清单

### 制作前

- [ ] 明确本镜头属于哪种骨架。
- [ ] 写出观众体验和游戏隐喻对应的真实含义。
- [ ] 标出主焦点的登场顺序（整镜最多两个）和三个景深层次。
- [ ] 核对关键文字安全区。

### 画面

- [ ] 色值全部来自 token。
- [ ] 字号、间距、描边、圆角符合范围；中文不小于 24px。
- [ ] `typography.font_files` 用到的每个字重都有 `@font-face`，`src` 指向镜头目录内真实存在的文件，且都是 `font-display: block`。渲染机不装系统字体，漏一条会静默回退成通用字体，本地看不出来。
- [ ] 亮色底上的文字对比度 ≥ 4.5:1。
- [ ] 标签、星星、金币距边缘至少 24px。
- [ ] 列表、日历格底部至少 24px。
- [ ] 无裁切、重叠、唇边方向不一致。

### 动画

- [ ] Build / Breathe / Resolve 完整。
- [ ] 弹性只作用于图形，文字 0.35s 内落定。
- [ ] 每镜头最多一种环境动作。
- [ ] 动画确定性、可寻址、任意帧可重建。

### 声音与交付

- [ ] 人声清晰且保持原速。
- [ ] BGM ducking 和淡入淡出正确。
- [ ] SFX 数量受控，一串星星只用一个 cue。
- [ ] 第 0 帧完成并稳定至少 18 帧。
- [ ] {{CANVAS}}、30fps、H.264/yuv420p/BT.709。
