---# “像素街机”视频风格说明书

- 版本：1.0
- 适用：复古游戏文化、怀旧与历史、入门科普、面向新手的技术基础、游戏化学习类竖屏解说
- 基准画幅：1080×1440，30fps

## 1. 风格定位

“像素街机”借用 8/16-bit 街机与家用主机时代的界面语言，把讲解变成一局小游戏：开机画面抛出问题，选角界面摆出对照，关卡地图走完步骤，道具栏清点能力。观众不需要懂游戏，也能靠对话框、光标、分数和血条这些人人熟悉的符号快速读懂信息层级。

五个关键词：

- **好玩**：用游戏符号降低理解门槛，而不是堆砌怀旧梗。
- **直接**：一个对话框说一句话，一个光标指一个焦点。
- **有节奏**：阶梯式跳格动作，像帧动画一样干脆。
- **锐利**：像素边缘清晰，直角、硬投影、无模糊。
- **克制**：调色板有限，金币黄只给当前焦点。

## 2. 适用与不适用

适合：

- 游戏史、主机与硬件科普、互联网怀旧。
- 面向新手的概念入门：把“学习路径”画成关卡，把“工具”画成道具。
- 需要轻松、年轻、有互动感的知识视频。

不适合直接套用：

- 严肃新闻、灾难、医疗与法律等需要庄重语气的题材。
- 大段论证、长引文和密集数据表：像素字不适合长文本阅读。

这些题材若要使用本风格，应减少游戏隐喻，只保留像素面板与调色板，把长文本交给 `Noto Sans SC`。

## 3. 品牌叙事原则

每个镜头先写一句“玩家体验”，再写布局：

> 玩家此刻看到了哪个界面？光标停在哪里？按下确认后什么被点亮？

优先使用以下叙事动作：

1. **开机**：标题卡出现，抛出问题或主张。
2. **选择**：光标在选项之间移动，停在答案上。
3. **闯关**：路径逐格点亮，关卡依次通过。
4. **获得**：道具被收进背包，说明框写出它的用途。
5. **结算**：分数或结论跳格落定，画面稳定。

## 4. 画布、安全区与像素网格

### 4.1 安全区

安全区以项目根 `frame.md` 的 `safe_area` 为准（`structural`、`main_content`、`critical_text`、`cover_title`、`subtitles` 五块），数值随画幅由构建期推导，不在本说明书里重复。

- 右侧与底部的平台互动区只允许星点、地面网格等非关键装饰进入。
- 标题、数字、结论、选中项和字幕不得进入平台避让区。
- 底部字幕带保持干净：不放对话框、血条或道具格。

### 4.2 像素网格

- 基础像素单位 6px：边框 6px，切角 6px，硬投影偏移 12px。
- 面板、图标、路径的坐标与尺寸都取 6 的倍数，避免半像素。
- 主内容左轴 88px，标准宽度 904px；面板可以横跨，但文字不越过关键文字区右界。

## 5. 色彩系统

调色板取自经典幻想主机的 16 色思路，收敛为 11 个 token：

| Token | 色值 | 用途 |
|---|---|---|
| canvas | `#1B1B2F` | 深夜街机画布 |
| panel | `#2B2B52` | 对话框、菜单与格子底 |
| shadow | `#0B0B16` | 硬投影、屏幕内陷、字幕底 |
| ink | `#FFF1E8` | 主文字 |
| frame_gray | `#C2C3C7` | 面板外框、分隔线 |
| muted | `#A6A6C8` | 辅助说明、未解锁状态 |
| coin_yellow | `#FFEC27` | 当前焦点：光标、分数、选中项 |
| p1_blue | `#29ADFF` | 1P、主方案、已通过路径 |
| p2_orange | `#FFA300` | 2P、对照方案、次强调 |
| power_green | `#00E436` | 完成、通过、满血 |
| hp_red | `#FF4D6D` | 风险、失败、扣血 |

对比度（WCAG）：`ink` 在 `canvas` 上 15.3:1、在 `panel` 上 12.1:1；`coin_yellow` 在 `canvas` 上 13.9:1；`p1_blue` 在 `canvas` 上 6.8:1、在 `panel` 上 5.4:1；`muted` 在 `panel` 上 5.7:1。`hp_red` 在 `canvas` 上 5.3:1，但在 `panel` 上只有 4.2:1，所以红色文字只放在 `canvas` 或 `shadow` 上，面板里的红色只做血条、图标等填充。

金币黄是全片最高权重的颜色，只给当前焦点，不作装饰。蓝橙两色只用于 1P / 2P 这类成对语义，不作装饰色轮换。

## 6. 字体与信息层级

### 6.1 字体角色

- 中文像素字：`Fusion Pixel 12px Prop zh-Hans`，用于标题、对白、选项和短标签。
- 拉丁像素字：`Press Start 2P`（分数、`PRESS START`、`STAGE 1` 这类街机字样），`Silkscreen`（更轻的英文标签与数值单位）。
- 长文本：`Noto Sans SC`，用于两行以上的说明。像素中文字体缺少部分二级汉字，遇到缺字时整句改用 `Noto Sans SC`，不要单字混排。
- 所有字体都必须随项目以 `@font-face` 嵌入，不依赖系统字体。

### 6.2 字号（只用整数倍）

| 角色 | 字体 | 字号 |
|---|---|---:|
| 封面标题 | Fusion Pixel | 72 / 96px |
| 镜头标题 | Fusion Pixel | 48 / 72px |
| 对白 / 选项 / 结论 | Fusion Pixel | 36 / 48px |
| 长说明 | Noto Sans SC | 28–34px |
| 分数 / 街机字样 | Press Start 2P | 24 / 32 / 48px |
| 英文标签 | Silkscreen | 24 / 32px |

中文像素字的网格是 12px，拉丁像素字是 8px；不在表里的字号会让笔画糊成灰边。像素字行高取字号的 1.17–1.34 倍，长说明约 1.45。

## 7. 形状与组件

### 7.1 形状语言

- 只用直角和 6px 切角（去掉四个角的一个像素），不用圆角。
- 边框 6px 实色，深度靠 12px 硬投影，不用模糊阴影与发光。
- 图标用 6px 像素块拼出，保持原创：心形、星星、钥匙、齿轮、宝箱、旗子这类通用符号即可。

### 7.2 组件

- **对话框**：`panel` 底、`frame_gray` 外框、右下角闪烁三角表示“还有下一句”。一次只放一句对白。
- **选项菜单**：竖排选项，金币黄 `▶` 光标指向当前项，未选项用 `muted`。
- **分数与血条**：`Press Start 2P` 数字、分格血条；数字必须是文案里的真实数字。
- **关卡节点**：方形节点加编号，已通过为 `p1_blue` 填充、当前为金币黄描边、未解锁为 `muted` 加锁。
- **背包格**：等宽方格阵列，选中格用金币黄外框，下方配道具说明框。

## 8. 四类镜头骨架

### 8.1 开机标题

用于封面、钩子、章节开场和强结论。一行街机字样、一个大标题、一个“按键开始”式提示。标题在第 0 帧已完整显示。

![开机标题示例](../assets/style-guide/examples/proposition.png)

### 8.2 双人选角

用于两种方案、旧与新、条件与结果。左右两张选角卡，1P 蓝、2P 橙，各自有属性条；结论写在下方对话框里，不塞进卡片。

![双人选角示例](../assets/style-guide/examples/comparison.png)

### 8.3 关卡地图

用于步骤、阶段、因果链和成长路线。蛇形路径连接关卡节点，按顺序点亮；当前关卡配一句说明。

![关卡地图示例](../assets/style-guide/examples/process.png)

### 8.4 道具栏

用于系统组成、能力清单、工具箱和最终成果。背包格阵列加一个说明框；选中的道具是唯一焦点。

![道具栏示例](../assets/style-guide/examples/capability_deck.png)

## 9. 动画语法

### 9.1 三阶段

- **Build 30%**：界面框先到，文字随后打出，焦点最后被光标点中。
- **Breathe 45%**：信息稳定可读，只保留一种环境动作；允许完全静止。
- **Resolve 25%**：计分落定、关卡通过或硬切退场。

### 9.2 品牌动作词

`POP_IN`（面板按 2–3 格放大弹出）、`TYPEWRITE`（逐字打出，每秒 12–24 字）、`BLINK`（光标或提示以 0.5–0.8s 周期闪烁）、`STEP`（按像素单位跳格位移）、`COUNT_UP`（数字跳 6–12 格落定）、`UNLOCK`（锁图标打开、节点点亮）、`POWER_UP`（血条或能量条分格填满）、`SELECT`（光标跳到选项并反色）。

入场 0.20–0.50s，退场 0.13–0.33s，缓动只用 `steps(n)`。第一动作延迟 0.10–0.30s，避免第 0 帧跳变。一个镜头中相同缓动的独立 tween 不超过两个。

### 9.3 转场

- 同一关卡内：光标移动、面板替换、硬切。
- 新章节：像素块擦除（方块阵列逐行填满再清空）或 0.20–0.40s 的方向性推移，位移按格跳。
- 重要信息出齐后稳定 1.0–1.8s，再允许切镜头。

禁止平滑缓动、弹性回弹、运动模糊、透明度淡入淡出作为主要动作，以及重度 CRT 弯曲与色差。

### 9.4 环境动作

每镜头最多一种：光标闪烁、星点闪烁或弱扫描线（透明度不超过 10%）三选一。信息出齐后可以没有任何环境动作，让画面安静地停留。

## 10. 字幕、口播与声音

### 字幕

- 可选，最多两行。
- 36px 像素字，最大宽度 812px，行距 1.34–1.50，每行不超过 16 个全角字符。
- `rgba(11,11,22,0.88)` 直角底框，12×24px 内边距。
- 专有名词、英文词组、数字与单位不可拆开；字幕不得压住光标、分数和选中项。

### 口播

- 保持人声原速，信息密集段之间留真实停顿。
- 打字机速度跟随口播，不为了打完字而拉伸人声。

### BGM 与 SFX

- 48kHz 双声道；BGM 可以是芯片音乐质感，但音量克制。
- 人声 stem -18 至 -16 LUFS；BGM -30 至 -26 LUFS，有人声时下压 6–10dB。
- SFX（投币、确认、升级、计分）只标记钩子、选择、解锁和结论，同时最多两个，单个增益 -18 至 -12dB。
- 打字机逐字音效要么整段关闭，要么极轻，不能盖过口播。
- 成片目标 -16 LUFS ±1，真峰值不高于 -1 dBTP，LRA 2–6 LU。

## 11. 首帧封面

- 第 0 帧必须是完整完成态：标题、面板、光标都已在位。
- 默认两行，最多三行；单行不超过 10 个全角字符，字号 72 或 96px。
- 文本与背景最低对比度 7:1。
- 30fps 下至少稳定 18 帧后才允许转场。
- 不得用黑帧、“INSERT COIN”空屏或逐字打出的中间态开场。

## 12. 不可变项与可变项

### 不可变

- 调色板、字体角色、整数倍字号、6px 像素网格、直角与硬投影。
- 四类骨架的语义用途。
- 阶梯缓动、动作词、三阶段节奏、人声优先的声音目标。
- 字幕、封面、禁用项和验收门槛。

### 可变

- 镜头骨架选择和组合。
- 原创像素图标、关卡数量、背包格数量、局部构图。
- 内容截图和实拍素材（放进像素边框里，不做像素化滤镜）。

商业游戏的 Logo、角色、道具造型和专有界面一律不得复刻；需要提及某款游戏时只写文字名称。

## 13. Do / Don’t

### Do

- 让光标和金币黄指向唯一的当前焦点。
- 用对话框一次只说一句话。
- 用关卡与背包这类结构承载真实的步骤和清单。
- 信息出齐后让画面静止停留，给观众读的时间。
- 缺字时把整句换成 `Noto Sans SC`。

### Don’t

- 不用非整数倍字号、缩放后发糊的像素图。
- 不加圆角、渐变、模糊阴影或霓虹发光。
- 不用弹性、平滑缓动和透明度淡入作为主要动作。
- 不复刻任何商业游戏的角色、Logo 和界面。
- 不让扫描线、星点压在关键文字上，不给每个元素配音效。

## 14. 制作与验收清单

### 制作前

- [ ] 明确本镜头属于哪种骨架。
- [ ] 写出玩家体验和界面隐喻。
- [ ] 同一时刻只有一个主焦点；整镜最多两个焦点，按节拍依次登场。
- [ ] 核对关键文字安全区与底部字幕带。

### 画面

- [ ] 色值全部来自 token，金币黄同一时刻只出现在一个焦点上。
- [ ] 像素字只用整数倍字号，边缘锐利。
- [ ] `typography.font_files` 用到的每个字重都有 `@font-face`，`src` 指向镜头目录内真实存在的文件，且都是 `font-display: block`。渲染机不装系统字体，漏一条会静默回退成通用字体，本地看不出来。
- [ ] 标签和图标距边缘至少 24px，列表底部至少 24px。
- [ ] 无裁切、重叠、缺字方块和半像素错位。

### 动画

- [ ] Build / Breathe / Resolve 完整。
- [ ] 缓动只用 `steps(n)`，入场顺序符合信息优先级。
- [ ] 每镜头最多一种环境动作，允许静止停留。
- [ ] 动画确定性、可寻址、任意帧可重建。

### 声音与交付

- [ ] 人声清晰且保持原速。
- [ ] BGM ducking 和淡入淡出正确。
- [ ] SFX 数量受控且不覆盖关键词。
- [ ] 第 0 帧完成并稳定至少 18 帧。
- [ ] 1080×1440、30fps、H.264/yuv420p/BT.709。
